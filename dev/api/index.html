Free space

BoxDMK.build_tree — Function
build_tree(f, kernel, basis; ndim=3, norder=6, eps=1e-6, boxlen=1.0, nd=1, eta=1.0, f_batch=nothing)
    -> (tree::BoxTree, fvals)

Adaptive tree on the box [0, boxlen]^ndim resolving the density f to relative tolerance eps (the Fortran builder: Legendre/Chebyshev tail test, 2:1 level restriction, colleague lists). f(x) returns the nd density values at the point x (a number when nd == 1); alternatively f_batch!(values, points) fills values (nd, npts) at points (ndim, npts) for a whole box at once, and f may then be omitted. fvals holds the samples, (nd, norder^ndim, nboxes).

BoxDMK.PotentialField — Type
PotentialField(tree, result)

Attach a SolverResult to its BoxTree so the solved potential (and, when computed, gradient/hessian) can be evaluated at arbitrary points of the domain [0, boxlen]^ndim.

The field is callable: field(x) evaluates the potential at a point x (returns a scalar for nd == 1, a length-nd vector otherwise), and field(X) evaluates at each column of a (ndim, ntarg) matrix. Use evaluate_potential, evaluate_gradient, and evaluate_hessian for output with explicit (nd, ...) shapes.

Evaluation locates the leaf box containing the point by descending the tree, then evaluates the box's tensor-product polynomial interpolant.

Periodic

BoxDMK.bdmk_periodic — Function
bdmk_periodic(f, cell; eps=1e-6, norder=16, rc_factor=0.25, nhalo=1, f_batch=nothing,
              skip_negligible=true, interpolate=true, sample_once=true, timings=nothing)

Periodic Coulomb potential

u(x) = ∫_cell Σ_n f(y) / |x - y - A n| dy        (k = 0 mode dropped)

of the cell-periodic density f(x::AbstractVector) -> Real. cell is the 3×3 matrix A of lattice vectors (columns), a 3-tuple L for the orthorhombic cell [0, L₁) × [0, L₂) × [0, L₃), or a number for a cube. A density with nonzero mean is taken with a uniform neutralizing background (the k = 0 mode of the whole potential is dropped). f_batch!(values, points) (values (1, npts), points (3, npts)) may be given instead of f. The level-0 boxes have side rc = d_min / ⌈1/rc_factor⌉, d_min the smallest distance between lattice planes. With skip_negligible boxes whose density is too small to change the potential by eps relative are left out of the real-space part (see _source_boxes). With interpolate (cells whose level-0 cubes do not tile the cell) only the boxes meeting the cell sample f, the others interpolate them at periodic images; false gives the forest of the C++ builder. With sample_once, f is evaluated only by the adaptive refinement of the boxes that meet the cell: the boxes added for the 2:1 balance take their parent's polynomial and the wide source tree of non-tiled cells interpolates the forest (values accurate to eps instead of to rounding; false samples f everywhere, as the C++ code). targets (3 × N points) restricts the computation to the leaves holding them and returns the potential there in target_pot. timings (length ≥ 6) receives wall times (s): [1] sampling (the adaptive refinement that evaluates f; with sample_once = false the whole forest), [2] the rest of the forest, setup and wide source, [3] local expansions + upward pass, [4] wide part, [5] plane waves, [6] near field, and if length ≥ 10 the plane-wave split [7] formation, [8] translation, [9] evaluation, [10] downward pass.

BoxDMK.periodic_plan — Function
periodic_plan(f, cell; eps=1e-6, norder=16, rc_factor=0.25, nhalo=1, f_batch=nothing,
              skip_negligible=true, interpolate=true, sample_once=true, targets=nothing,
              near32=nothing) -> PeriodicPlan

Forest (adapted to f), tables and buffers of bdmk_periodic, for repeated solves with periodic_solve!; the options are those of bdmk_periodic. With targets (3 × N points), only the leaves holding a target are computed and solves return the potential at the targets (target_pot). near32 runs the dense same-level near field in single precision (default: when eps ≥ 1e-6).

source
BoxDMK.PeriodicPlan — Type
PeriodicPlan

Forest and precomputation of bdmk_periodic for repeated solves on a fixed forest (e.g. time stepping): plan = periodic_plan(f, cell; kwargs...), then periodic_solve!(plan, f) for each new density (the first solve uses the samples taken by the plan). The result of a solve shares the plan's buffers (pot, fvals), which the next solve overwrites. The forest is adapted to the density given to periodic_plan; later densities must be resolved by it.

Quasi-2D

BoxDMK.bdmk_q2d — Function
bdmk_q2d(f, L, zlim; eps=1e-6, norder=16, rc=nothing, f_batch=nothing, timings=nothing, ...)

Quasi-2D (slab) Coulomb potential: periodic in x and y with the rectangular cell L = (L₁, L₂) (or a number for a square), free in z,

u(x) = ∫ Σ_{n ∈ ℤ²} f(y) / |x - y - (n₁L₁, n₂L₂, 0)| dy,

for a neutral density f that vanishes outside the slab zlim = (z₀, z₁). The potential is computed in the slab (evaluate_periodic(res, x) for z₀ ≤ x₃ ≤ z₁). The level-0 boxes have side rc ≤ min(L₁, L₂, z₁ - z₀), which must divide both in-plane sides; by default the largest such value. The real-space (narrow) part is that of bdmk_periodic with images in x and y only; the wide part is summed in the plane over the modes k̇ = 2π(m₁/L₁, m₂/L₂) and applied in z through exact Gaussian kernel matrices on the level-0 z-cells, the mode k̇ = 0 through the kernel -2π|z - z'|/(L₁L₂) of all wide Gaussians. Other options and timings as for bdmk_periodic; the forest and res.pot are in the frame (x, y, z - z₀).

BoxDMK.LaplaceKernel — Type
LaplaceKernel()

The Laplace kernel K(r) = 1/r (3D), so that u = ∫ K f solves -Δu = 4π f.

source

source
